Sistema de cruce de RIPS

Herramienta para identificar automáticamente posibles cruces en cartera a partir de archivos de Excel.

El sistema analiza registros con el mismo Cliente y OrdenMv, clasificándolos en:

  • Cruces exactos con saldos opuestos.
  • Grupos de registros cuya suma total es cero.
  • Casos con el mismo Cliente y OrdenMv que requieren validación manual.
